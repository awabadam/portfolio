## 🎯 Key Baseline Insights

### The diagnosis: Low visibility + low CTR + wrong niche
- **178 impressions in 28 days** = ~6/day. This is **tiny**. You're essentially invisible on Google right now.
- **1 click in 28 days** at 0.56% CTR. Normal is 3-5% for positions 10-15. You're under-performing even for your low rankings.
- **Average position ~11** = top of page 2. Barely any of your queries break into page 1.
- **Zero impressions for ANY of our Phase 2/3 target keywords** — which is actually good news: there's no existing ranking to lose, only upside to gain.

### The biggest opportunity: `"web development"` at position 8
- **45 impressions = 25% of all your traffic** comes from this one generic query
- At position ~8 you're on page 1 already — but at the bottom
- Moving 8 → 4 could 5-10x CTR (2-3% → 10-15%)
- **But** — this is a very generic query without local intent. The click value is low unless they become local leads.

### The homepage has a CTR problem
- **93 impressions at position 5.63 but ZERO clicks**
- Being on page 1 in position 5-6 should yield 5-8% CTR minimum
- Likely causes:
  1. **The old title/description** wasn't compelling (we fixed this in Phase 1 — new title: "Web Designer Istanbul | Next.js & Multilingual Sites | Awab Design")
  2. **"web development" is a broad query** where searchers pick developer tools / tutorials / agencies, not a freelancer portfolio
- Phase 1 metadata rewrite should directly impact this — measure at +14 days

### `/services/webdesign-istanbul` is Google's "you almost fit" page
- **28 impressions at position 33.5** — Google knows the page exists and is trying to rank it for Istanbul queries, but it's deep on page 4
- This is actually the most improvable page — if we can get it to page 1-2, it unlocks `"web design agency istanbul"` (19 impressions at position 40)
- **Action for Phase 2+**: improve this page's content, add more keyword coverage, internal links pointing to it

### Mobile traffic is abnormally low (11.5%)
- Turkey's mobile share is ~80%. Yours is 11%.
- But the mobile AVERAGE position is **4.0** (much better than desktop's 17.87)
- Hypothesis: You're actually ranking well on mobile for a handful of queries, just very low volume because Google isn't showing the site to many mobile users
- Could also indicate: **homepage fails Core Web Vitals on mobile** → Google demotes mobile indexing. Worth checking mobile CWV explicitly.

### Country mix is healthy for targeting
- **Turkey: 56 impressions (72%)** at good position 8.02 ✓
- **US: 22 impressions (28%)** at deep position 37.27 — US queries are too generic to compete on
- **Missing**: Arab world, France — no impressions despite having AR/FR locales. The locale pages barely have any impressions (`/tr/about` = 3 imp, `/tr` = 2 imp). These locales need their own Phase 3 push.

### The `.vercel.app` subdomain question
- None of the top pages in this report show `.vercel.app` URLs — they all show `www.awab.design`
- Either (a) preview URLs aren't actually polluting this specific view, or (b) the GSC property you exported from is already scoped to awab.design only
- Worth checking in GSC: Settings → Property type — if it's a "Domain" property, preview URLs would show here. If it's "URL prefix" for `https://www.awab.design`, preview URLs would be in a separate property.
