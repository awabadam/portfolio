# Blog Images Directory

This directory contains featured images for blog posts.

## Image Requirements

- **Format**: JPG, PNG, or WebP
- **Dimensions**: 1200x630px (16:9 aspect ratio) for optimal social sharing
- **File Size**: Keep under 500KB for fast loading
- **Naming**: Use descriptive names like `web-design-trends-2024.jpg`

## Current Blog Posts

1. `web-design-trends-2024.jpg` - Web Design Trends That Will Dominate 2024
2. `seo-tips-designers.jpg` - SEO Tips Every Web Designer Should Know
3. `freelance-design-tips.jpg` - Freelance Design Success: Tips from an Istanbul Designer

## Image Sources

You can use:

- Unsplash (free stock photos)
- Pexels (free stock photos)
- Your own photography
- Generated images (ensure you have rights)

## Optimization

Before uploading:

1. Compress images using tools like TinyPNG
2. Convert to WebP format for better performance
3. Add descriptive alt text in the blog post content
